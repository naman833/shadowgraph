# DataHub agent skills

This directory vendors the five official DataHub catalog workflow skills plus
their shared usage instructions:

- `datahub-setup`
- `datahub-search`
- `datahub-lineage`
- `datahub-enrich`
- `datahub-quality`
- `using-datahub`

They were installed from
[`datahub-project/datahub-skills`](https://github.com/datahub-project/datahub-skills)
at commit `f22f93074cf265ba6f9401947404f090c2584d9d`.

These files are portable agent instructions. They do not connect the project to
Codex, OpenAI, or any paid API. At runtime they use DataHub's official MCP tools
or the open-source DataHub CLI.
